# Имитационная модель «Сеть АЗС»

Модель на Python + SimPy, смоделировано 8 АЗС и 12 мини-АЗС, 4 вида топлива, бензовозы
2-3 секции по 6000 л, две стратегии снабжения по критическому уровню и по времени,
моделирование 10 суток

## Запуск
    pip install -r requirements.txt
    python run.py      # прогоны + таблицы в консоль + CSV в results/
    python plots.py    # графики в results/*.png 
    python tests.py    # проверки корректности модели, т.е баланс топлива, перелив, пороги

## Файлы
- `config.py` - все параметры и допущения 
- `model.py`  - сама модель: станции, клиенты, менеджер, диспетчер, бензовозы
- `run.py`    - запуск, среднее и 95% доверительный интервал по N_RUNS=10 прогонам, вывод и CSV
- `plots.py`  - графики для отчета
- `tests.py`  - проверки: заказ целых секций, защита от перелива, порог, баланс топлива, одинаковые клиенты у стратегий
- `results/`  - результаты последнего запуска

## Допущения (не заданы в условии)
1. Время в минутах. Random(3) - равномерное на [0; 3] мин
2. Емкости баков берутся по видам топлива, в условии есть противоречие с общими объемами 42000/24000 л
3. Клиенты приходят общим потоком: интервал = Random(3) / 56 (число ТРК в сети), затем распределяются по правилам условия
4. Скорость заправки 40 л/мин; одна ТРК = 2 канала обслуживания
5. Клиент ждет колонку не дольше 5 мин; если топлива в баке меньше нужного объема - уезжает. Это необслуженные
6. Парк бензовозов неограничен. Время до первой станции 60 мин, между станциями 15 мин
7. Стратегии: а) заказ при запасе с учетом заказанного <= 25% емкости бака; б) долив каждые 6 ч, фаза случайная для каждой станции. Заказываются целые секции, помещающиеся в бак
8. В начале моделирования баки полные
9. Диспетчер раз в 10 мин собирает заявки и формирует рейсы по 3 секции; остаток из 1-2 секций едет на 2-секционном бензовозе. Рейс относится к дню отправки
10. Закупочная цена топлива не задана, поэтому оценивается выручка как в условии, а прибыль без себестоимости не считается

## Случайность
- Клиентский поток и таймеры станций используют разные генераторы случайных чисел `seed` и `seed + 10000`
  Поэтому обе стратегии сравниваются на одинаковых потоках клиентов, т.е одинаковое число клиентов, виды топлива и объемы
- Конкретная станция внутри группы выбирается равновероятно, для 98 и ДТ - среди 8 АЗС,
  для 92/95 - среди АЗС или среди 12 ААЗС в зависимости от случайного фактора Random(100) < 50.
- Результаты - это среднее по 10 прогонам (зерна 12345-12354) и полуширина 95% ДИ (распределение Стьюдента)
